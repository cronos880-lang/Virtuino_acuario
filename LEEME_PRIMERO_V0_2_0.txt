ACUARIS V0.2.0 — VERSIÓN EXPERIMENTAL DE PRUEBA
================================================
NO es una versión oficial. Sirve para probar y perfeccionar el editor.
Entrega COMPLETA (código fuente). No incluye ningún .exe propio: se ejecuta
con el motor Godot 4.7.2, igual que Electrical Work se ejecuta con Python.

INSTALACIÓN (en una carpeta aparte, sin tocar nada más)
1. Descomprime el ZIP en una carpeta NUEVA, por ejemplo:
      Documentos\Acuaris_V0_2_0
2. Ejecuta INICIAR_WINDOWS.bat
   - La primera vez, si no está el motor, pregunta [S/N] para descargar
     Godot 4.7.2 oficial (unos 82 MB) a la carpeta "motor" de Acuaris.
     No se instala nada en Windows.
   - Después prepara el proyecto unos segundos y abre el editor.
3. Comprueba que el título de la ventana indica «Acuaris V0.2.0 Editor».

Si Windows muestra "Windows protegió su PC" al abrir Godot: "Más información"
y "Ejecutar de todas formas" (Godot es oficial pero Windows a veces avisa).

OTROS LANZADORES
- PROBAR_APP_MOVIL.bat ...... la app del móvil en el PC, con el simulador.
- INICIAR_CON_CONSOLA.bat ... el editor con una ventana de mensajes; úsalo si
                              algo falla y mándame una captura de esa ventana.

USO DEL EDITOR
- "Acuario": abre tu interfaz original (protegida: se guarda con otro nombre).
- "Nuevo": interfaz desde cero eligiendo móvil, tablet o PC y orientación.
- Paleta (izquierda): clic para añadir o arrastrar al dispositivo.
- Ratón: mover; tiradores amarillos: estirar. Rejilla de 4 dp.
- Propiedades (derecha): pin, posición, tamaño, textos, colores...
- "+ Página" / pestañas: varias páginas.
- "Ajustar", "+", "−", "1:1" (tamaño real aproximado): zoom.
- "▶ Probar": la interfaz funciona con el simulador del acuario.
- Teclado: Supr borrar · Ctrl+D duplicar · flechas mover (Mayús x4)
           Ctrl+Z deshacer · Ctrl+Y rehacer · Ctrl+S guardar

DATOS
- Tus proyectos se guardan donde elijas (por defecto Documentos\Acuaris).
- Todo lo demás queda dentro de la carpeta de Acuaris.
- Desinstalar: borrar la carpeta. Tus proyectos .acuaris.json se conservan.

PRUEBA RECOMENDADA
1. Abre "Acuario", cambia algo (color, texto, posición) y "Guardar como…".
2. Cierra, vuelve a abrir el archivo guardado y comprueba que está igual.
3. "Nuevo" para una tablet en horizontal; añade elementos, páginas, Probar.
4. Prueba Deshacer/Rehacer, zoom y 1:1.
5. Anota lo que quieras cambiar o lo que falle (mejor con capturas).

LÍMITES CONOCIDOS
- Primera prueba en Windows real.
- Las interfaces nuevas aún no se pasan al móvil (siguiente fase).
- El Bluetooth solo funciona en la app de Android.
